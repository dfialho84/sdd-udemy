Está é a especificação para a feature registrar-usuario.

Seu principal valor para o negócio é possibilitar que usuários possam acessar o sistema de forma segura e diferenciada. Ou seja, cada usuário, é único.

A feature trata do auto cadastro feito pelo próprio usuário. Ele acessará o sistema, haverá um link para ele se cadastrar. CLicando nele, poderá realizar seu proprio cadastro, informando:

nome
email (unico no sistema)
senha (deve ter n miniomo 8 caracteres e conter maiusculas, minusculas, números e caracteres especiais)
Confirmação de senha
foto de perfil.
Data de nascimento
O sistema deverá enviar um email com um link único e expiravel para o usuário confirmar o cadastro. SOmente apos isto seu cadatro ficará completo. Antes disto, o cadastro está pendente. Caso o link expire, o cadastro pendente é deletado.
