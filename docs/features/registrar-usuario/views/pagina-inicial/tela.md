# Pagina Inicial

## Visao Geral

- **Nome:** Pagina Inicial
- **Slug:** pagina-inicial
- **URL:** /
- **Objetivo:** Receber o visitante na plataforma e oferecer acesso ao cadastro, permitindo que qualquer pessoa inicie o processo de criacao de conta sem intervencao administrativa.
- **Scenarios relacionados:**
  - Acessar formulario de cadastro via link na home

## Componentes

### Links de navegacao

| Rotulo | Destino | Contexto |
|---|---|---|
| Criar conta | /register | Exibido na pagina inicial; ao clicar, leva o visitante para a pagina de cadastro |
